## 5. 미충족 (숨기지 않고 기록)

| 항목 | 상태 | 근거 |
|---|---|---|
| **토큰 무효화** | ❌ 없음 | 탈취 토큰 최대 12시간 유효 (AP-3). 무상태 유지의 대가 |
| **무차별 대입 차단** | ⚠️ 지연만 | 백오프는 늦출 뿐이다. 분산·저빈도에 무력 |
| **악성 파일 차단** | ⚠️ 구조 검증까지 | 안티바이러스 아님. 파싱 자체가 공격면 |
| **`/usage` 권한** | ⚠️ 로그인만 | 역할 구분 없음. FR 에 역할이 없다 |
| **익명 질의 이력** | ⚠️ 설계상 없음 | `owner_id NULL` = 아무의 이력도 아님 (BR-151 의 대가) |
| **비밀번호 재설정·계정 삭제** | ❌ 미구현 | FR 에 없다. 메일 발송·캐스케이드 정책이 전제된다 |
