| 유닛 | FR | 컴포넌트 | FR당 컴포넌트 | 성격 |

## 6. 추적성 유지 규칙

1. **각 FR은 정확히 하나의 유닛이 소유**한다. 다른 유닛이 그 FR의 화면·기능을 확장하는 경우
   (예: FR-48 운영 화면) 확장하는 쪽은 **자신의 FR로** 처리한다
2. **Code Generation 단계마다 `traceability.md` 를 갱신**하여 FR → 컴포넌트 → 파일 경로를 기록한다 (QG-1)
3. **NFR은 여러 유닛에서 검증될 수 있다.** 위 §3의 "검증 유닛"은 **최초 검증 시점**을 의미하며,
   이후 유닛에서도 회귀하지 않아야 한다
4. **Functional Design 이월 17건**(`components.md` §15)은 각 유닛의 Functional Design 착수 시
   해당 항목을 확정하고 목록에서 제거한다
